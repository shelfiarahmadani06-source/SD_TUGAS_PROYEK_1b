# SD_TUGAS_PROYEK_1B
## Aplikasi Silsilah Organisasi - General Tree

### Deskripsi
Program ini merupakan prototype aplikasi manajemen
Silsilah Organisasi menggunakan bahasa Python,
Object-Oriented Programming (OOP), dan struktur data
General Tree.

### Fitur
1. Menampilkan struktur organisasi.
2. Menambahkan pegawai atau jabatan.
3. Mencari pegawai berdasarkan ID, nama, atau jabatan.
4. Preorder Traversal.
5. Inorder Traversal.
6. Postorder Traversal.

### Struktur Folder
- models: menyimpan kelas Node.
- structures: implementasi General Tree.
- data: data organisasi.
- views: tampilan aplikasi.
- tests: pengujian program.
- main.py: program utama.

### Teknologi
- Python
- Object-Oriented Programming
- General Tree
- Depth First Search (DFS)

### Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka terminal.
3. Jalankan:

   python main.py

### Pengujian
Jalankan perintah:

   python -m unittest -v

### Analisis Kompleksitas
- Preorder: O(n)
- Inorder: O(n)
- Postorder: O(n)
- Search: O(n) kasus terburuk.
- Insert: O(n) termasuk pencarian atasan.

### Catatan
Inorder pada General Tree menggunakan konvensi
anak pertama, node, kemudian anak berikutnya.
General Tree tidak mempunyai definisi inorder
baku seperti Binary Tree.
